# Live Church Translation

[English](README.md) | 简体中文

Live Church Translation 是一款注重隐私的 macOS 教会现场翻译应用，支持普通话到英语和英语到
简体中文。它可录制会话、生成带时间戳的听抄稿，并向可信局域网内已配对的设备提供只读实时页面。

## 主要功能

- 在设备本地完成语音识别和翻译，不使用云端推理。
- 支持选择音频输入、完整本地录音、意外退出恢复和可搜索的原文资料库。
- 可导入 WAV、AIFF/AIFC、AAC/M4A 和 CAF 录音。
- 提供可编辑术语表和自动译文校验。
- 连续阅读界面包含克制的处理状态、可选原文与时间戳，以及“返回最新内容”。
- 可向已配对的手机、平板和电脑提供只读局域网共享。

自动校验可以减少已知结构错误，但不能保证语言或神学准确性。重要译文必须由合格的双语人员复核。

## 系统要求

- Apple Silicon Mac（M1 或更新机型）。
- macOS 15.0 或更高版本。
- 安装包与应用同时存在时至少保留 5 GB 可用空间。

分发安装包内置经过校验的模型和运行组件，使用者无需安装 Python、Node.js、Ollama 或其他推理环境。

## 使用

1. 打开应用并允许麦克风访问。
2. 选择翻译方向、音频输入和术语表。
3. 确认现场人员知晓会被录音，然后点击“开始”。
4. 在本机阅读，或在可信网络中开启“共享”供已配对的听众查看。
5. 点击“停止”，在“资料库”中完成录音和听抄稿的保存。

也可从“资料库”导入已有录音进行听抄。

## 隐私与局域网共享

语音识别和翻译均在本机运行。资料库保留录音和语音识别原文，不保留译文；术语表和恢复数据也
保存在应用沙盒容器的 Application Support 目录中。

局域网共享默认关闭，听众无法控制录音或应用设置。当前阅读页面使用经过身份验证但没有 TLS 的
HTTP/WebSocket，因此只能在可信局域网内开启，并应在使用后停止共享。请勿进行端口转发，也不要在
不可信的公共 Wi-Fi 上使用。

数据处理详情请参阅[隐私政策](PRIVACY.md)。

