# ScriptureQualificationSupport

Validates a gitignored, tester-provided ESV 2025 and CUNPSS-Shen 1988 evaluation corpus.
The gate checks exact edition identity, tester-provided text/audio source
attribution, hashed use declarations, private paths, source hashes, evaluation-only use,
explicit non-weight model-adjustment use, and no-training/no-redistribution constraints.
Public values expose verified file URLs and aggregate metrics, never reference text.
