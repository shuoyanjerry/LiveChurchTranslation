# AudioFileAVFoundation

Bounded, streaming AVFoundation decoding for user-selected audio files. The production adapter
requests non-interleaved Float32 PCM from `AVAudioFile`, reads one bounded buffer at a time, and
balances security-scoped access on completion, cancellation, and failure.

The mandatory host matrix covers WAV, AIFF, AIFC, CAF, raw AAC/ADTS, and AAC in M4A with temporary
English and Mandarin speech generated by macOS. MP3 is routed through the same production adapter;
the default gate skips it because macOS 15's `afconvert` exposes no MP3 encoder. On 2026-08-22, a
local private-QA run supplied a rights-safe MP3 and successfully decoded the bounded prefix of
16 × 100 ms chunks. No private audio or source path was committed or copied. This qualifies the
decoder/container path only, grants no redistribution permission, and must be repeated against the
exact signed release candidate before claiming MP3 support.
