# AudioFileAVFoundation

Bounded, streaming AVFoundation decoding for user-selected audio and approved movie containers.
The production adapter reads non-interleaved Float32 PCM from `AVAudioFile`, balances
security-scoped access on every exit, and validates a real audio frame before an import session is
created. It also reserves the decoded PCM16 size plus at least 1 GiB of free-space headroom.

The mandatory matrix covers WAV, AIFF, AIFC, CAF, raw AAC/ADTS, AAC/M4A, and FLAC with temporary
English and Mandarin speech generated by macOS. It also creates real H.264/AAC MOV, MP4, and M4V
files and rejects a movie without an audio track. MP3 uses the same decoder; its opt-in lane requires
a rights-safe local fixture because the system converter exposes no MP3 encoder. No fixture is
committed.
